## 阅读主线

- **问题从哪里来？** 作者观察到了什么现象，如何找到已有方法的不足？
- **思路如何形成？** 核心假设是什么，为什么选择这条解决路径？
- **方法如何落地？** 各个设计怎样回应问题，有没有更简单的替代方案？
- **效果如何验证？** 实验是否支持设计动机与作用解释，适用边界在哪里？
- **我能借鉴什么？** 哪种思考方式或研究方法可以迁移到自己的问题中？

具体分析、公式疑问和核查过程放在单篇笔记中，区分作者结论、个人理解与待验证的想法。
